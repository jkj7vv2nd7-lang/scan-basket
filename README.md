# スキャン買い物かご（単体HTML版）

バーコードを読み取って買い物かごに入れ、税込合計と予算を管理するアプリです。`index.html` 1ファイルで動きます（アイコン用に `icon.png` を一緒に置きます）。

## GitHub Pagesでの公開手順
1. GitHubで新しいリポジトリ「scan-basket」を作ります
2. `index.html` と `icon.png` をアップロードします
3. リポジトリの Settings → Pages で、公開するブランチ（main）を選びます
4. 数分待つと公開されます

公開URL： https://jkj7vv2nd7-lang.github.io/scan-basket/

iPhoneのSafariで開いて「ホーム画面に追加」すると、専用アイコンでアプリのように使えます。

## データについて
- 価格メモ・買い物リスト・カゴ・予算は、その端末のブラウザの中にだけ保存されます。サーバーには送られません
- Museライブラリ版とはデータは共有されません（単体版は空の状態から始まります）

## 注意
- カメラでの読み取りはブラウザの対応状況に依存します。iPhoneのSafariなど対応していない環境では、JANコードの手入力が主な使い方になります（手入力でも全機能が使えます）
